The problem

Agents write code fast. What they lose just as fast is the why.

A decision made in one session is forgotten in the next, and the reasoning stays in a chat log nobody reads again. The same knowledge ends up in the code, the docs and the build, and each copy ages at its own pace. The faster the code grows, the harder it gets to review.

A model gives humans and agents one source to work from: it states the intent, and it stays when the technology changes.
